# 資工所應試教材、題庫與書籍清單（含電子檔與解答）

> **目的**：作為出模擬試題的來源。本清單依科目整理市面上合適的應試教材，並標明「電子檔」與「解答」取得狀況。
> **重要說明**：
> 1. 以下均為**正規販售管道**（電子書平台、出版社、雲端課程），不包含任何非授權分享。
> 2. 「電子檔」指合法電子書或雲端課程講義；「解答」指題目附解析或官方解答。
> 3. 原文教科書的 Instructor's Solutions Manual 通常僅對教師公開，學生未必能直接取得，已於表中註明。

> **建議優先順序**（以出模擬試題為目的）：
> 1. **試題大補帖系列** — 每冊皆「歷屆考題＋逐題解析」且有電子書，直接對應各校考古題，最適合作為模擬試題來源。
> 2. **黃子嘉／張凡／洪逸／林立宇《研究所講重點》** — 含精選試題與詳解，作為題目改編基礎。
> 3. **Strang 線代** — 解答免費公開，方便自組題目。
> 4. **原文書**（CLRS/Rosen/Silberschatz/計組）— 適合取得概念性證明題，但完整解答多僅教師可用。
