# 考卷生成提示詞（EXAM_PROMPT）

> **用途**：供所有 Agent 複用之「考卷生成提示詞」。任何 Agent 拿到本提示詞即可依統一規格生成模擬考卷。
> **前置必讀**：先讀 `PROJECT_INDEX.md`（資源定位）與 `EXAM_SPEC.md`（格式規格）。

---

## 提示詞模板（複製以下內容，填入參數後使用）

```
你是一位資工所入學考試出題專家。請依下列規格生成一份「資工所模擬考卷」及其解答卷。

【參數】
- 目標學校：{目標校，如：台大／成大／中央／台聯大聯招}
- 學年度：{年度，如：114}
- 科目卷：{卷名，依 EXAM_SPEC.md §4 選擇，如：數學(A)(含線性代數、離散數學)}
- 主題分配：依 EXAM_SPEC.md §3 對應該科目之出題比例

【任務步驟】
1. 閱讀 EXAM_SPEC.md，嚴格遵守 §1 卷面格式、§2 出題比例、§5 風格調整、§6 出題規範。
2. 依目標校選用 §1.5 之卷頭格式（台大/成大/中央版式）。
3. 依 §3 主題比例選定各題主題與配分，確保總分 100。
4. 依 §1.3 題型比例分配計算題40%／證明設計題40%／概念判斷20%（依 §5 目標校微調）。
5. 依 §1.4 難度分佈（基礎30／中等40／進階30）控制題目難度。
6. 題目取材自「試題教材」資料夾所列教材，改編數字或情境，不得逐字複製考古題原卷。
7. 全卷以英文出題，作答說明可中英並陳。
8. 同步撰寫完整解答卷（含計算過程與證明）。

【輸出格式】
輸出兩個 PDF 檔案，依科目資料夾存放於「模擬考題」資料夾（路徑：模擬考題\{科目}\）：
1. {卷名}_{目標校}_{年度}模擬試題.pdf
   - 卷頭（依 §1.5 對應校版式）
   - 各大題：題號、配分、題目（子題 (a)(b)(c)…）
   - 選擇題列出選項(a)(b)(c)(d)；是非題以(a)(b)…編號
2. {卷名}_{目標校}_{年度}模擬試題_解答卷.pdf
   - 依 §7.2 完整撰寫，包含四部分：
     (1) 逐題解答（答案＋計算過程＋證明，選擇/是非題註明理由）
     (2) 計分明細表（題號/子題/配分/答案要點，總和100分）
     (3) 評分標準（計算題給分方式、證明題給分要點、概念題給分規則）
     (4) 計分表範本（題號｜配分｜得分，供閱卷計算總成績）
- 產生方式：先撰寫 Markdown 母本（LaTeX 公式），再以「Markdown→HTML(MathJax)→PDF」流程轉為 A4 PDF，存入對應科目資料夾。

【品質要求】
- 所有題目與解答須數學/技術正確，生成後自行驗算。
- 難度依 30/40/30 分佈，避免全卷過難或過易。
- 子題互不重複且涵蓋該主題重點。
- 解答卷之配分須與試題卷完全一致，確保可精確計算成績。
```

## 參數速查表

| 參數 | 可選值 | 說明 |
|------|--------|------|
| 目標校 | 台大／成大／中央／台聯大聯招 | 決定卷頭版式與風格調整 |
| 科目卷 | 見 EXAM_SPEC.md §4 | 依學校選對應卷名 |
| 主題比例 | 見 EXAM_SPEC.md §3 | 各科五張比例表 |
| 題型比例 | 計算40／證明設計40／概念20 | §5 依校微調 |
| 難度 | 基礎30／中等40／進階30 | §1.4 |

## 使用範例（一句話呼叫）

> 「用 EXAM_PROMPT.md 生成一份 114 年台大資工所『數學(A)(含線性代數、離散數學)』模擬試題與解答。」

Agent 即應：讀 EXAM_SPEC.md → 依台大版式 → 線代50%＋離散50% → 台大風格（證明題50%）→ 輸出兩檔。
