# 資工所模擬試題 — 考卷格式規格（EXAM_SPEC）

> **版本**：v1.0（2026-09）
> **用途**：所有 Agent 生成考卷時，必須依本規格製作。本規格參考台清交成中央等校 **114 學年度**碩士班入學考古題之卷面格式與命題結構制定。
> **範圍**：線性代數、資料結構與演算法、離散數學、作業系統、計算機組織與結構 五科。

---

## 1. 卷面通用格式（依各校 114 年考古題格式）

### 1.1 卷頭（每份試卷開頭）

```
國立○○大學○○學年度碩士班招生考試試題
系所組別：○○○○○○
科目名稱：○○○○○○
（編號：○○○　日期：○○○○　節次：第 ○ 節）　※視目標校格式選擇
作答時間：180 分鐘

作答說明：
1. 本試題共 ○ 大題，總分 100 分。
2. 請將答案依序書寫於答案卷上，並標明題號。
3. 計算題須列出計算過程，證明題須寫出完整推導。
4. 不得使用電子計算機（除非題目指定）。
```

- 依目標校調整「國立○○大學」「科目名稱」「系所組別」與卷頭欄位。
- 科目名稱對應表見 §4。
- **114 年實測之卷頭欄位差異**（見 §1.5）：
  - 台大：卷頭含「題號：296　科目：數學(A)　節次：4」，右上「共 2 頁之第 1 頁」。
  - 成大：卷頭含「編號：149　系所：電機資訊學院-資訊聯招　科目：計算機數學　日期：0210　節次：第 3 節」＋「注意：1.不可使用計算機　2.請於答案卷(卡)作答」。
  - 中央：卷頭含「系所：資工類　科目：離散數學與線性代數」＋「本科考試禁用計算器」，右上「第 1 頁 / 共 9 頁」。

### 1.2 題號與配分規則

| 項目 | 規則 |
|------|------|
| 大題編號 | 一、二、三…（成大式「一、離散數學(50%)」）或 1. 2. 3. … |
| 子題編號 | (a) (b) (c) … |
| 配分標示 | 兩種皆可：(1) 每大題標百分比「一、○○(50%)」；(2) 每小題標百分比「1. (10%)」（台大/成大/中央實測皆用百分比） |
| 分部分結構 | 可依中央式分「第一部分／第二部分」並註明「共 XX 分、單選題、每題 X 分、錯一題倒扣」等規則 |
| 大題配分 | 各大題合計 100 分 |
| 子題配分 | 每小題標明「(10%)」，確保各子題配分和 = 大題配分 |
| 題數 | 6–8 大題（依科目） |
| 版面 | 每大題後預留作答空間，須清楚標示題號與配分 |
| 語言 | **全英文出題**（114 年台大/成大/中央實測皆為英文題目，可加中文作答說明） |

### 1.3 題型分類（三類，比例固定）

| 題型 | 佔比 | 說明 |
|------|------|------|
| **計算題** | 40% | 機械式/步驟式計算，如求 rank、Gantt 圖、缺頁次數 |
| **證明/設計題** | 40% | 證明正確性、設計演算法（含 pseudocode）、推導 |
| **概念判斷題** | 20% | 是非/選擇/簡答，考定義與取捨比較 |

> 依目標校風格可微調（台大提高證明/設計至 50%；中央提高概念判斷至 30%），見 §5。

### 1.4 難度分佈

| 難度 | 佔比 | 對應 |
|------|------|------|
| 基礎 | 30% | 直接套用定義/公式之題 |
| 中等 | 40% | 需 2–3 步推理或中等計算 |
| 進階 | 30% | 證明、跨主題整合、鑑別題 |

### 1.5 114 年實際卷面格式參考（視覺辨識實測）

> 以下為以視覺工具實測三校 114 學年度考古題原卷所得之真實版面，供出題時比照。

| 學校 | 卷頭欄位 | 題號/配分格式 | 題型特色 |
|------|----------|--------------|----------|
| **台大**（數學(A)） | 「國立臺灣大學 114 學年度碩士班招生考試試題」＋題號/科目/節次 | 「1. (5%)」「3. (10%)」逐小題標百分比 | 多選「Which ones of the following…」＋填空（_____）＋計算；英文 |
| **成大**（計算機數學） | 「國立成功大學 114學年度碩士班招生考試試題」＋編號/系所/科目/日期/節次/注意 | 大題「一、離散數學(50%)」「二、線性代數(50%)」，小題「1. (10%)」 | 單選(a)-(d)、是非題(a)-(e)各(2%)；英文 |
| **中央**（離散數學與線性代數） | 「國立中央大學 114 學年度碩士班考試入學試題」＋系所/科目/禁用計算器 | 「第一部分：共20分，單選題，每題5分，錯一題倒扣2分」＋「1.」題號 | 單選(a)-(e)、倒扣規則、分部分；英文 |

**格式規範化結論**：
1. 卷頭固定為「國立○○大學○○學年度碩士班招生考試試題」＋系所/科目/頁碼，頁尾「第 X 頁，共 Y 頁」。
2. 配分一律以百分比標示：大題「一、○○(50%)」或小題「1. (10%)」。
3. 題目全英文；作答說明可中英並陳。
4. 選擇題須列選項(a)(b)(c)(d)（或(e)）；是非題以(a)(b)…編號並標各小題配分。

## 2. 出題比例總原則

出題比例依下列三項決定：
1. **高頻範圍**：考題整理報告中各主題的 ★ 頻率（★★★★★ = 最高權重）。
2. **命題趨勢**：近年加重之主題（如 DP、證明題、SVD、管線 hazard）提高權重。
3. **題型趨勢**：計算/證明/概念判斷之配比。

> 各科主題權重詳見 §3，最終比例已加總為 100%。

## 5. 各校風格調整規則

| 學校 | 調整 |
|------|------|
| **台大** | 證明/設計題提高至 50%，概念判斷降至 10%；加重 DP、greedy 證明、NP 理論、線性映射與內積 |
| **成大** | 計算題提高至 50%；保持基本+應用並重；加 IEEE 754、資料結構操作題 |
| **中央** | 概念判斷提高至 30%；選擇/是非題增加；題目難度中等偏基礎 |
| **台聯大聯招** | 電機類風格，計算題為主；資料結構/離散/計組獨立卷 |

## 6. 出題規範（所有 Agent 必須遵守）

1. **題目來源**：優先取材自「試題教材」資料夾所列教材（試題大補帖、研究所講重點、原文書），並依 §3 比例出題。
2. **不抄襲原卷**：不得逐字複製各校考古題原卷，應改編數字、情境或敘述（結構與風格可比照）。
3. **必附解答**：每份考卷須另附「解答卷」，含完整計算過程與證明。
4. **正確性**：所有題目與解答需數學/技術上正確，Agent 需自行驗算。
5. **難度平衡**：依 §1.4 難度分佈（30/40/30），避免全卷過難或過易。
6. **子題完整**：每大題之子題須互不重複且涵蓋該主題重點。

## 7. 輸出格式

每份考卷輸出**兩個 PDF 檔案**，依科目資料夾存放於 `模擬考題\`：

```
模擬考題\{科目}\{卷名}_{目標校}_{年度}模擬試題.pdf       ← 試題卷
模擬考題\{科目}\{卷名}_{目標校}_{年度}模擬試題_解答卷.pdf ← 解答卷
```

- **科目資料夾**：資料結構與演算法／線性代數／離散數學／作業系統／計算機組織與結構。
- **PDF 來源**：以 Markdown 為母本（含 LaTeX 公式），經 MathJax 渲染後列印為 A4 PDF（中文字體 Microsoft JhengHei）。
- 同時保留 Markdown 母本於專案根目錄（或與 PDF 同目錄），供 Agent 編輯/重新轉檔。

### 7.1 試題卷
- 含 §1.1 卷頭、各大題（題號、配分、題目），符合 §1.5 目標校版式。

### 7.2 解答卷（必要，以利計算成績）

解答卷必須包含下列四部分：

**（1）逐題解答**
- 依題號（含子題 (a)(b)(c)…）逐題給出：答案、完整計算過程、證明推導、最終答案。
- 選擇/是非題須註明正確選項及簡短理由。

**（2）計分明細表（配分對照）**
- 以表格列出每大題/每子題之配分，確保與試題卷標示一致、總和 100 分。

| 題號 | 子題 | 配分 | 題型 | 答案要點 |
|------|------|------|------|----------|
| 一 | (a) | 5 | 計算 | … |
| 一 | (b) | 5 | 證明 | … |

**（3）評分標準（Rubric）**
- 計算題：註明「最終答案正確 X 分；過程正確但答案錯 Y 分；過程錯誤 0 分」之給分方式。
- 證明題：列出給分要點（如「正確使用歸納假設 +3 分」「正確結論 +2 分」）。
- 概念題：註明「全對才給分」或「部分給分」規則（比照原卷，如中央「錯一題倒扣」）。

**（4）計分表（供閱卷計算成績）**
- 提供空白計分表範本：列「題號｜配分｜得分」，總分欄位自動加總 = 100。
- 供使用者或 Agent 依考生作答填入得分、計算總成績。
